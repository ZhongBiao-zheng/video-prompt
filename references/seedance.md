# Seedance / 即梦心法（详写骨架）

> 2026-10-19 起默认写法由「简派」改为「详写骨架」。原因：写不清的部分模型会自己补，补出来的内容通常质量差（作者实测判断）；长片实践也表明，镜头间的人物、站位、光线一致性靠逐段写清来维持（Higgsfield Studio《HELL GRIND》95 分钟长片，Seedance 2.0 生成，prompt 常写到 3,000–4,000 词，2026-08）。
> 简派保留下来的结论：只出音效不要 BGM、不放华丽故事板、用 720P、清晰度靠后期、事件按因果顺序、台词按字数预算。

## 原则

- **长度不是问题，单个节拍塞太满才是问题。** 整条 prompt 可以很长；时间轴里每个节拍最多 3 句，塞满了模型会糊。
- **没写到的东西模型会自己编。** 人数、家具数量、站位、光向、谁说话、谁沉默，凡是重要的都写出来。
- **开头定调。** 模型对 prompt 前部的注意力更高：人数、媒介、发生什么、每份参考的用途放在最前面，骨架的段序就是按这个排的。（来源：Higgsfield 动画团队《Passport Rush》教程，"前 20% 最重要"，2026-09；待自测）
- **只写画面里有什么。** 否定式（"不要摔向后面"）常被忽略或反向执行，改成肯定式（"向前扑倒"）；禁令集中在最后一段，也写成"画面里恰好有……"。
- **写行为和物理，不写情绪词。** "愤怒""悲伤"会让模型随意发挥；写下颌、呼吸、眨眼、视线、手上的动作。
- **项目常量逐字粘贴。** 角色描述、声音描述、空间地图、风格前缀在同一项目里每条 prompt 原样带入，不缩写，不写"同上"。

## 骨架（12 段）

每段用中文标签开头，按顺序写。与本条无关的段可以写一句"无"或省略（例如无台词时声音段只写音效），其余段都写。

```
场景概述：恰好 N 个角色，不重复：[谁]。[风格媒介一句：写实电影 / 手机实拍 / 2D 赛璐珞…]。[地点、时间]。[发生什么]。[单镜一镜到底 / 硬切 N 镜]，[时长] 秒，[画幅]。
参考素材：
@Image 1 用作角色参考：[完整可见人物：脸、发型、服装、体型、配饰]；不继承背景、姿势、构图。
@Image 2 用作场景参考：只取空间和材质；不作为首帧，不继承构图、角度和调色。
[题材锁：相机 / 产品 / 画风 / 节奏，命中题材配方时一项一行]
空间地图：[地标物及位置，用"画面左 / 画面右 / 画面中央"和米数]；机位在[哪一侧]，全片不越过[哪条轴线]。
首帧站位：[第一帧谁在哪、朝向哪、看向哪]。第一帧画面已经是完整站位，没有空镜开场。
镜头：[焦段约 X°/Xmm]，[机位高度、距离]，[对焦方案]；[运动方式]，[不做的运动：不推、不变焦、不甩]。
动作时间轴：
Shot 01（0-3s）：[可见动作]。[可见动作]。[结束状态]。
Shot 02（3-6s）：……
物理：[有重量的东西怎么动：惯性、接触、落地、液体、布料]。
光线：[单一光源逻辑：光从哪来、照到哪、哪里暗多少]。
声音：只要现场音效，不要音乐，不要字幕。[环境声]。[角色] 声音（原样）："[声音描述]"。台词只有："[原文]"。其他人不说话。
角色表演：[角色]——状态：…；想要：…；隐藏：…；身体节奏：…；变化点：…。
风格：[项目风格前缀，逐字粘贴；无项目时写具体的媒介、光影、色彩、镜头质感，不写 8K / 梦幻 / 治愈这类空词]。
约束：画面里恰好 [N 个人 / N 件道具]，没有其他人。[道具数量与位置锁]。[机位轴线锁]。[身份 / 服装全片一致]。只要音效，无 BGM，无字幕。
```

## 各段写法

**场景概述**
- 第一句写死人数："恰好 3 个角色，不重复：A、B、C"。模型喜欢加人、复制家具，这句防它。
- 参考图里没有的人，画面里就不该有。

**参考素材**
- 每个 `@` 都写用途、保留什么、不继承什么。不写用途时模型自己判断，常见错误是照抄构图而丢了脸。
- 人物参考默认锁完整可见人物；用户说"只参考脸"才缩窄。多主体每人一行。
- 图里已有的外观不用文字重写一遍：保留项写类别名（脸、发型、服装、配饰），可以加"100% 按原图"。只有图里看不清、而镜头又要用到的细节（某个配饰、某处伤痕）才单独点名。重写的细节和图对不上时，模型要在两者之间取舍。
- 场景参考必须写"不作为首帧，不继承构图、角度和调色，只取空间和材质"。
- 同一角色的不同状态（湿身、受伤、换装）是不同素材，分开引用，不在一段文字里混写。

**空间地图**
- 方位只用画面视角："画面左 / 画面右"。模型不理解"主角的左边"。
- 位置用地标 + 米数："在灯旁，离门 3 米"。"在房间里"等于没写。
- 写明机位在哪一侧、永不越过哪条线，所有切镜保持在同一轴线。
- 同一场戏的多个镜头，空间地图逐字相同。场景外观仍来自场景参考图，地图只管位置关系。
- 静态对话只给房间一角：空间越小，模型放错人的余地越小。

**首帧站位**
- 一场戏的第一条生成，第一秒用远景固定站位：没有台词、没有动作，让模型先"拍下"谁在哪、光从哪来。可以让某人说一个短音（"嗯"）帮模型把这一秒当成独立镜头。
- 本条接上一条时，把上一条最后一句台词放进开头这一秒，语气和口型能接上。
- 每次切镜后重新写一遍谁在哪、看向哪。模型不记得上一镜。

**动作时间轴**
- 2.0 和 2.5 都按秒写节拍，秒段首尾相接、总和等于时长。（2026-10-19 起取消"2.0 写秒段是安慰剂"的旧结论；长片实践在 2.0 上按秒写节拍有效。）
- 现在时、短句，每个节拍最多 3 句。机位动作写在节拍里。
- 复杂动作不要放在中段起步：直接从"已经在挥击中，门已经在裂开"开始；走到门前另拍一条。
- 一镜到底时秒段只代表表演节拍，不代表切镜。
- ≥30s 在编号后加【阶段功能】（2–4 字），超长视频按幕 / 场写，见 `seedance-director-workflow.md` §5。

**物理**
- 写重量和接触：重的东西拖慢身体、晚半拍摆动；液体会晃、会稳住；落地要屈膝吸收。
- 巨型角色每条都写尺寸对比，并在画面里放一个人作参照（"人只到它的脚踝，头和脚无法同框"），否则模型会悄悄把它缩回人的尺寸。
- 人群写明人数（"20 人以上"），否则一条 3 人、下一条 100 人。
- 风格化世界先写世界规则：这个世界里什么成立、什么不成立（角色可以被压扁再弹回、车可以腾空半秒、雨只下在画面右半边）。不写，模型按真实物理处理。
- 动画片在这段点名 2–4 条要用的动画原则，并写成可见动作，写法见 `seedance-genre-recipes.md` §4「动画原则」。

**光线**
- 一个光源逻辑、一个阴影方向，全片不出现两个太阳。光从哪来、哪边暗几档写清楚。
- 两个空间之间转场，接缝放在门槛上，用门两侧的光色对比（暖黄房间 / 冷蓝走廊）。对比能解释色调变化，也能掩盖小的几何误差。

**声音**
- 只要现场音效，不要音乐：音乐属于后期，生成里自带配乐会妨碍剪辑。
- 角色声音描述（音域、语速、口音、说话方式）在项目里锁定，每次原样粘贴。
- 台词只写在声音段，动作时间轴里不出现说话内容。
- 写硬约束："每人只说引号里的台词；没有台词的人完全沉默"。动作里写的"半笑"是表情，不出声。模型会自己加"嗯"、笑声甚至整句。
- 写混音关系：人声干净近麦，环境声在下面，有人说话时环境声压低。
- 生僻名字给读音，否则会念错。
- 台词按 3–5 字/秒预算，留出听、停顿、反应的时间。塞不下时先加长时长或拆成两条；删改台词等于改剧本，先问用户。
- 在节拍里可以写"A 开口说话"标出说话时机，台词原文仍只放在声音段。

**角色表演**
- 写行为不写情绪：给角色一个目标、一个阻碍，让争取方式在镜头里变化（开玩笑 → 施压 → 哀求），每次变化是一个可见事件（停顿、换姿势、换节奏）。
- 写肌肉不写形容词：下颌咬紧又松开、颧骨绷紧、鼻腔轻呼气。
- 加一句内心意图，标"内心（不说出口）"。
- 分阶段眨眼：一次慢眨 → 快速双眨 → 一次用力的眨眼。写清视线方向，或者写眼神游移。
- 静态镜头每 1–2 秒安排一个微事件（呼吸抬起胸口、鼻翼动、眉头紧了又松）。静止写成"绷住的张力"；"所有人一动不动"会把画面冻住。
- 反应先于对方说完；重大事件后给角色零点几秒消化再开口；情绪有余波，呼吸和手还没稳下来。
- 让角色手上有事（修东西、数钱、倒水）；一场戏最重的那一下，是他因为听到某句话停下手上的活。
- 角色行为档案在项目里锁定；场景里做不到的习惯要转换表现方式，不要删掉（爱踱步的人坐着时改成腿抖、敲手指）。

**风格**
- 有项目时，风格前缀是常量，逐字贴在每条结尾，改一处全片同步。
- 写可见的物理条件（自然动机光、逆光、薄雾、180° 快门运动模糊、毛孔级皮肤、24fps），不写不指向画面的空词。

**约束**
- 数量写死："恰好一个人体模型，不出现第二个"。
- 用户没给的禁令按题材补：无字幕、无 BGM、无新增人物道具、某事件不得提前。
- 最后一帧停在哪写清；要收干净写"硬切黑"，不写"淡出"（模型会真的淡出，占掉约 2 秒）。
- 画面里要出现的文字、logo 留到后期，不交给模型生成。
- 任何语言都不写年龄。写到未成年时内容过滤会明显变严；用身份、服装、动作代替。

## 敏感词替换

模型对部分词会降质或触发过滤。遇到时换写法，项目里维护一份替换表：

| 原词 | 替换 |
|---|---|
| dark / 黑暗 | low key / 低调光 |
| jolting / 猛地一震 | rapid motion / 快速动作 |
| 年龄数字、"少年""小孩" | 身份 + 服装 + 动作 |

## 示例

请求：「Seedance 2.5，10 秒 16:9。@Image 1 是老修表匠，@Image 2 是他的店。他修好一块旧表，学徒推门进来，他只说一句"放那吧"。」

```
场景概述：恰好 2 个角色，不重复：修表匠、学徒。写实电影质感。小镇钟表店，傍晚。修表匠刚修好一块旧怀表，学徒推门送来新的活。单镜一镜到底，10 秒，16:9。
参考素材：
@Image 1 用作修表匠的角色参考：脸、发型、服装 100% 按原图，包括左眼的放大镜片；不继承背景和姿势。
@Image 2 用作场景参考：只取店内空间、木柜和玻璃柜台材质；不作为首帧，不继承构图、角度和调色。
空间地图：工作台在画面中央，台灯在工作台左端；店门在画面右后方，离工作台约 4 米；墙上挂钟群在画面左后方。机位在工作台正前方，全片不越过工作台与店门的连线。
首帧站位：修表匠坐在工作台后，身体朝画面左，低头看手里的怀表；店门关着，学徒在画面外。
镜头：约 40mm，胸口高度，离工作台 2 米；景深覆盖工作台和店门；呼吸感手持，只在修表匠抬头时微调构图，不推、不变焦、不甩。
动作时间轴：
Shot 01（0-3s）：修表匠用镊子把最后一枚齿轮按进机芯。秒针开始走动。他停住呼吸看了一秒。
Shot 02（3-6s）：店门被推开，学徒抱着一个纸盒进来，停在门口一米处。修表匠的眼睛先抬起来，头随后转过去。
Shot 03（6-10s）：修表匠把怀表轻轻扣上，放到台灯下，下巴朝工作台右侧空位点了一下。最后一帧停在怀表在灯下反光。
物理：纸盒有分量，学徒的手臂微微下沉；怀表盖扣上时有轻微回弹。
光线：台灯是唯一主光，从画面左侧照亮修表匠的手和怀表；店门方向暗两档，门外是冷蓝的傍晚天光。
声音：只要现场音效，不要音乐，不要字幕。挂钟群的滴答声，门铃一声，纸盒摩擦声。修表匠声音（原样）："低沉沙哑，语速慢，句尾下沉"。台词只有："放那吧。"学徒不说话。人声近麦，说话时环境声压低。
角色表演：修表匠——状态：专注后的松弛；想要：再多看一眼修好的表；隐藏：被打断的不耐烦；身体节奏：慢、稳，手比头先动；变化点：学徒进门时把情绪收回到平淡的脸。
风格：写实电影剧照质感，自然动机光，暖黄台灯与冷蓝门外天光对比，35mm 胶片颗粒，180° 快门运动模糊，毛孔级皮肤。
约束：画面里恰好两个人，没有其他人；恰好一块怀表、一盏台灯；机位始终在工作台正前方；修表匠服装全片一致；只要音效，无 BGM，无字幕。
```

## 流程与模式

- **题材**：请求属于 22 类题材之一时，读 `references/seedance-genre-recipes.md`，把题材的必写项写进对应段（题材锁写在"参考素材"段末，禁止项写进"约束"）。
- **分档**：≤15s、素材 ≤2 → 轻档，按骨架直接写；16–30s 或素材 3–5 或有台词 → 中档，加素材锁定表；30s+ / 长视频 / 延长 / 编辑 / 白模 / 无缝转场 / 多宫格 / 导演方案 → 重档，走全 9 步。细则见 `references/seedance-director-workflow.md`。
- **输出模式**：默认 `prompt-only`（一个代码块）；另有 `full-direction`、`script-only`、`diagnosis-only`、`revision`。
- **标签**：素材统一 `@Image N / @Video N / @Audio N`，按上传顺序编号；用户说「图1」就映射成 `@Image 1` 并在代码块外注明。
- **项目常量**：用户在做多镜头短片且已有角色描述、声音描述、空间地图、风格前缀时，逐字带入，不改写。

## 出稿前自检

1. 场景概述第一句写了确定人数。
2. 每个 `@` 都对应用户真给的素材，写了用途、保留、不继承。
3. 空间地图用画面方位 + 地标 + 米数，写了机位侧和轴线。
4. 秒段首尾相接、总和等于时长；每个节拍不超过 3 句。
5. 动作全是肯定式；事件按因果顺序（先触发再反应）。
6. 台词只在声音段，写了"其他人不说话"；字数在预算内。
7. 表演段写的是行为和肌肉，没有情绪形容词。
8. 约束段写了数量锁、轴线锁、无 BGM、无字幕，最后一帧写清。
9. 没有写年龄；画面里没有要模型生成的文字。

## 保留的实测结论

1. **不放华丽故事板**——带运动曲线 / 表格的故事板丢进去反而错漏百出。（2.5 官方的「多宫格分镜」推荐简约线稿 / 火柴人，构图和运镜仍靠 prompt 控制。）
2. **用 720P，不是 1080P**——对提示词响应最好，又快又便宜。（2.5 输出档位官方就是 480p / 720p。）
3. **清晰度靠后期**——定稿后用 Topaz 放大到 4K（注意有的镜头会被过分锐化）。
4. **抽卡与迭代**：同一 prompt 抽 3 次挑素材；一个镜头迭代 10–15 次还不成，问题不在措辞，拆成两条、删一个动作或换角度。每次迭代只改一行，记日志。

**Seedance 2.0 官方补充**（2026-08 官方使用手册；这里只补硬约束和官方语法，详见 `references/seedance-2.0-official.md`）：

- **输入上限**：图 ≤9 张；视频 ≤3 个、总 2–15s；音频 ≤3 个、总 ≤15s；**混合输入总上限 12 个文件**——写 prompt 前先确认素材没超限。生成时长 4–15s。
- **⚠️ 写实人脸拦截**：图片 / 视频素材含可辨识真人脸会被系统直接拦截、无法生成——真人质感只能文字描述，不能传照片。
- **入口只有两个**：首尾帧（首帧图 + prompt）/ 全能参考（多模态组合）；智能多帧、主体参考不可选。
- **@素材语法**：多次 @ 同一素材更准；多主体用编号法「将@Video 1中的小猫作为主体1」防串；音色可单独指定「旁白音色参考@Video 1」；没音频素材可直接参考视频里的声音。
- **延长 gotcha**：「将@Video 1延长 5s」时，生成时长选**新增部分**的时长（5s），不是总时长。

**Seedance 2.5 官方补充**（2026-08 官方使用手册；写作手法不变，以下是新的可用空间和官方数字）：

- **时长档位**：单次直出最长 30s（duration 4–30s）；「超长视频」模式最长 180s；已生成的 ≤30s 视频可多次「套娃」延长，最长到 60s。15s/5–6 镜的抽卡策略照旧，只是叙事长了可以直接要 30s。
- **输入上限（多模态参考）**：图片最多 30 张（4K 内）；视频最多 10 段、总时长 ≤30s；音频最多 10 段、总时长 ≤30s；支持**仅传音频**驱动生成（2.0 必须至少有图或视频）。
- **官方素材建议**：参考图 1–5 张效果最好（6–8 张可试但要抽卡）；主体图 1–5 个主体单图 / 多视图均可，超过 5 个主体用单视图更稳；要多视角就**拆成多张不同视图的图**，别塞一张多视角拼图（多图多视图 > 单图多视图）；主体音视频 5–10s 效果最好，主体数 1–8 佳；视频编辑的输入片段 ≤20s 效果最好。
- **音乐铁律更稳了**：2.5 大幅修复了随机字幕 / 无关 BGM 乱入，还支持用提示词**移除原视频 BGM 只留人声**（字幕等画面元素保留）——「只出音效、不要 BGM」这条铁律不变，出货更干净。
- **可提示能力清单**（2.5 写 prompt 时能直接指挥的东西）：时间戳卡点、白模控制（用无纹理 3D 白模锁机位 / 站位 / 运动轨迹）、绿幕、局部消除与编辑、空间视角修改（改机位并外推补全画外空间）、两段视频无缝转场补间、迁移创意（复刻参考视频的运动 / 情绪 / 镜头语言 / 网感）、音色参考、多人参考（修复"双胞胎脸"）、小语种直写（中文直接写，无需翻译）。
- **官方场景配方**（详见 `references/seedance-2.5-official.md`，按需取用；常规叙事按上面的 12 段骨架写，配方里的段落映射到对应段）：
  - 无参考素材 / 通用 → 官方基础公式：素材描述 + 一句话概述 + 分时间轴情节（正向+反向描述）+ 全局补充
  - 要真人脸 / 治 AI 脸、双胞胎脸 → 真人人物 8 维度公式（含「保留真实微细毛孔与肌肤纹理」强制保真后缀）
  - 30s 长视频 → 三模块：多模态参考层 + 全局设定（含禁止项防崩坏）+ 时间戳剧本分镜（物理指令 + 情感潜台词）
  - 60–180s 超长视频 → 开头加全局参数（时长/画幅），其余同基础公式按秒段直写
  - 视频延长 → 必含「向前延长 / 向后延长 / 延续 / 续写」+ 衔接约束；要切镜就套转场公式（官方 11 种转场词库在 reference 里）。「向前 / 向后续写」中文有歧义，先问「新增片段放原片之前还是之后？」；prompt 只描述新增区间并声明原片不变
  - 两段视频无缝转场 → 开头声明「无缝连接@Video 1 与@Video 2，不修改两段原视频」，再写视频1 出点、全屏过渡态、视频2 入点，锁形状 / 位置 / 方向 / 速度
  - 多宫格分镜 → 声明「@Image 1 是 N 格有序完整分镜，每格一个镜头」，角色 / 场景另 @ 图；每格对应一个 Shot
  - 智能编辑 / 高级编辑 / 视频编辑 → [标注工具与方位] + [修改对象] + [动作与变化] + [生效时序]
  - 白模 → 粗颗粒度（动态骨架，5 段公式）/ 细颗粒度（渲染上色，4 段公式）；当前粗颗粒度效果更好
