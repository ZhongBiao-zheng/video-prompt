# Seedance 2.0 官方使用手册要点（摘录 2026-08）

> 来源：《🎬 即梦 Seedance 2.0 使用手册（全新多模态创作体验）》官方 docx 文档（2026-08-05 摘录）。
> 与 B 节简派的关系：简派就是 2.0 时代实测出来的写作手法，两者同代不冲突。本文件补的是官方**硬约束**（输入上限 / 入口 / 人脸拦截）和 **@素材指挥语法**——写 prompt 前先确认素材没超限，写法仍按简派。

## 1. 参数硬约束（超限直接废）

| 维度 | 上限 |
|------|------|
| 图片 | ≤9 张，单张 <30MB（jpeg/png/webp/bmp/tiff/gif） |
| 视频 | ≤3 个，总时长 2–15s，单个 <50MB，像素 640×640（480p）–834×1112（720p）；带参考视频价格更高 |
| 音频 | ≤3 个，总时长 ≤15s，单个 <15MB（mp3/wav） |
| 混合输入 | 总上限 **12 个文件**——优先传对画面/节奏影响最大的素材 |
| 生成时长 | 4–15s 自由选 |
| 声音输出 | 自带音效/配乐（简派铁律照旧：prompt 里写明只要音效、不要 BGM） |

## 2. 入口与交互

- 只有两个入口：**首尾帧**（只传首帧图 + prompt）和**全能参考**（图/视频/音频/文本组合输入）。智能多帧、主体参考在 2.0 下不可选。
- 交互统一用 `@素材名` 指定用途：`@图片1 作为首帧，@视频1 参考镜头语言，@音频1 用于配乐`。
- **多次 @ 同一素材更准**——关键镜头处重复 @，并注明情绪、时序、各环节细节。
- 素材多时提交前自查：各 @对象有没有标清楚，图 / 视频 / 角色别搞混。

## 3. ⚠️ 写实人脸拦截（合规硬限制）

图片和视频素材**都不能**包含可辨识的写实真人脸——系统自动拦截，上传后无法生成。手册里所有真人 case 均标注"实际生成可能受限"。要真人质感只能靠文字描述（2.5 的真人 8 维度公式），不能传照片。

## 4. @素材指挥语法（官方 case 提炼）

- **主体编号法**（多主体防串）：先声明再引用——`将@视频1中的小猫作为主体1，将@视频1中的主人作为主体2`，后文全用「主体N」叙事；配武器/道具同理（`主体1的武器为@图片3主体3`）。
- **首帧 + 动作参考**：`@图1为首帧，参考@视频1的打斗动作`。
- **运镜/特效/节奏复刻**：`完全参考@视频1的所有运镜效果`、`参考@视频1的转场和运镜，一镜到底`、`视频节奏参考@视频`（卡点）。不懂术语没关系，写清参考哪部分即可。
- **声音**：没音频素材可直接参考视频里的声音；音色单独指定——`旁白的音色参考@视频1`、`背景 BGM 参考@视频3 中的音效`。
- **视频融合**：`我要在@视频1和@视频2之间加一个场景，内容为 xxx`。
- **视频编辑**（改已有视频）：指定片段/动作/角色定向修改，其余不动——`视频1中的女主唱换成图片1的男主唱，动作完全模仿原视频，不要出现切镜`；也可整体改写：`颠覆@视频1里的剧情` + 新故事线。
- **情绪标注**（可选技法）：官方 case 在秒段后用括号给表演指令——`6-11秒，……（情绪：惬意、享受）`。这是给模型的表演指令，不是渲染文案，与简派"句句是事件"不冲突；表演戏（哭/崩溃/对话）可用，普通叙事不必。

## 5. 视频延长（2.0 写法 + 关键 gotcha）

- 写法：`将@视频1延长 5s` / `向前延长10s` / `延长原视频时长到10秒，补充后续画面`。
- **⚠️ 生成时长选「新增部分」的时长**——延长 5s 就选 5s，不是总时长。
- 延长段按秒段写故事线，并交代与原画面的衔接（如「0-5秒先呈现@视频1 原画面，6-8秒接着……」）。

## 6. 2.0 vs 2.5 速查

| | 2.0 | 2.5 |
|--|-----|-----|
| 生成时长 | 4–15s | 4–30s；超长模式 180s；套娃延长至 60s |
| 图片上限 | 9 张 | 30 张（4K 内） |
| 视频上限 | 3 个 / 总 2–15s | 10 段 / 总 ≤30s |
| 音频上限 | 3 个 / 总 ≤15s | 10 段 / 总 ≤30s；支持纯音频驱动 |
| 时间戳 | 不真按时间戳分配（安慰剂） | 官方支持，可精确到秒 |
| 服务器紧张时 | 可切 Seedance 2.0 Fast | — |

（2.5 详细写法公式见 `seedance-2.5-official.md`。）
