# Seedance 导演手法补充（吸收自 liyue-aigc/seedance-2-5-video-director，2026-09-04）

> 来源仓库：https://github.com/liyue-aigc/seedance-2-5-video-director（MIT）。该仓库面向 Seedance 2.5 的高控制度导演流程（9 步工作流 / 素材锁定表 / 导演方案输出）。本 skill 的 B 节走简派，只吸收其中与「句句是事件、prompt 别求长」不冲突的手法；被放弃的部分列在文末。

## 1. 参考素材作用域契约

一条参考引用 = 来源 + 借什么 + 给谁 / 哪个 Shot + 不继承什么。

- 弱：`参考@Video 1 的动作。`
- 强：`Shot 03 参考@Video 1 中「预备—冲刺—起跳—挥砍」的重心和动作节奏，映射到@Image 1 的小骑士；不继承@Video 1 的人物、场景材质和声音。`

一个素材承担多种用途时拆开写。动作参考默认不控制身份 / 背景 / 音频 / 风格。

## 2. 人物参考图的默认范围

「人物参考图 / 角色参考图 / 严格参考人物图」默认等于完整可见人物：脸、发型发色、肤色、年龄感、身高体型比例、可见服装、鞋、配饰、整体气质。

- 不重设计、不换色、不增减可见服装配饰，除非用户明确允许换装。
- 图里看不到的背面按可见的版型 / 颜色 / 材质一致地补全，不另发明一套衣服。
- 默认不继承参考图的背景、构图、姿势、文字、裁切、光线。
- 用户说「只参考脸 / 只锁身份」才缩窄范围，此时服装算创作补充。
- 一张图里有多人：按位置或用户命名分别绑定，保持相对身高；禁混脸、换装、复制人、角色对调。
- 多主体各占一行、各 @ 自己的图（莎玛范例已是这种写法）。

## 3. 因果顺序

### 表演链

`刺激 → 理解停顿 → 第一反应 → 选择的反应 → 残留情绪 → 下一拍`

- 每拍只给 1–3 个可见线索：视线转移、呼吸变化、未完成的手势、握力变化、姿态变化、咽下的话、迟到的回答。
- 上一拍的情绪要残留进下一拍：笑慢慢收、怒里透伤、决绝和眷恋可以同时在。
- 不逐条写眉 / 眼 / 鼻 / 嘴的动作清单，那会得到机械表情。
- 红脸：可选、轻微、渐进、不均匀；优先用回避视线 / 呼吸 / 语速代替。
- 落泪：先呼吸变、眼眶湿、眨眼节奏变，最后才一滴泪；不能开场就满脸泪，除非剧情从哭完之后开始。
- 笑：从压抑或触发点起，结束后保留残余的呼吸和肩动，不从中性直接跳到大笑再跳回。

### 物理链

`原因 / 机制 → 接近 → 接触 → 力的方向 → 身体或物体的反应 → 恢复或结果 → 下一状态`

- 接触之前不出反应；触发之前不出水花 / 灯光 / 声音 / 跌倒。
- 湿、疲劳、损伤、手持道具、位置变化要累积，不能下一个 Shot 自动复原。
- 因果链塞不进该 Shot 就减事件，不压缩链条。

## 4. 台词预算

普通话自然情绪表达约 3–5 字/秒；短促争吵可到 5–6；犹疑、哭、潜台词需要更多时间。停顿、倾听、打断、呼吸、动作都占该 Shot 的时间。塞不下先删台词。

对手戏的关键一拍常常是听到之后的反应，给听的人画面时间。

## 5. 视频延长的方向规范

- 「原片之前 / 补前情 / 前传 / 衔接首帧」= 在原片之前插入；「原片之后 / 接着结尾 / 然后 / 继续故事」= 在原片之后追加。
- 「向前续写 / 前向续写 / 往前延长 / 向后续写 / 后向续写」在中文里有歧义，不从剧情推断，先问一句：「新增片段放在原片之前，还是原片之后？」问清再写。
- 开头句：`参考@Video 1 的原始内容，在原片之前插入 / 在原片之后追加 X 秒。原视频区间保持不变，以下只作用于新增区间。`
- 之前插入：新增段的结尾要接到原片首帧的状态（机位、动作、光、空间、声音）。之后追加：新增段从原片末帧状态起。
- 禁止项：无解释的重置、硬切、突然出现的道具、身份变化、光线跳变、声音断裂。

## 6. 两段视频无缝转场

开头句：`无缝连接@Video 1 与@Video 2，不修改两段原视频的既有内容。`

再写五件事：① 视频1 的出点动作或视觉触发；② 全屏过渡态（遮挡物 / 相似物 / 模糊 / 粒子 / 光 / 镜头穿越）；③ 进入视频2 的入点动作；④ 连接锁：形状、屏幕位置、大小、方向、速度、运动趋势、镜头矢量、颜色 / 材质变化、声音桥；⑤ 禁止项：黑帧、跳帧、硬切、闪烁、文字、标志、字幕。

## 7. 多宫格分镜

- 声明：`@Image 1 是包含 N 个连续镜头的完整分镜，每一格代表一个完整镜头，不是独立人物或场景参考。`
- 角色、道具、环境另 @ 各自的图。
- 每格对应一个 Shot：构图、机位高度与景别、主体动作、空间关系、结束状态。
- 分镜图用简约线稿 / 火柴人即可，外观、环境、运动、渲染细节靠 prompt 给。

## 8. 转场需要交代的控制点

只在剧情和物理上有动机时才用转场（官方 11 种转场释义见 `seedance-2.5-official.md` §5）。

| 转场 | 要写清的控制点 |
|------|--------------|
| 自然切换 | 呼吸感、动作或视线匹配、时长不突兀 |
| 淡入淡出 | 黑 / 白状态与时长 |
| 叠化 | 重叠时长、构图匹配 |
| 白闪 / 黑闪 | 触发的声音或动作、闪的确切时刻 |
| 擦除 | 方向、速度、遮挡边 |
| 遮罩 | 遮挡物、全遮状态、揭开方向 |
| 相似物 | 共享的形状、位置、大小、颜色、运动 |
| 甩镜 / 动作转场 | 甩的方向、力度、模糊、B 段入画方向 |
| 动态接力 | 连续的身体动作与落地姿态 |
| 拉近 / 拉远 | 目标细节、占满画面的时刻、揭示目标 |
| 水墨 | 墨的触发、扩散方向、揭示时机 |

## 9. 出稿前的矛盾自检

- 一镜到底 vs 正反打 / 切镜 / 视角瞬移
- 固定社交距离 vs 脸占满画面
- 第三人称 vs 镜头归某个角色（POV）
- 「不要两人同框」vs 肩膀、倒影、剪影、前景虚化里出现另一人
- 完整人物参考 vs 重设计服装配饰
- 精确时长 vs 塞不进去的台词和动作
- 自然表演 vs 逐肌肉表情清单
- 不要 BGM vs 又要配乐
- 保护原片 vs 全局改风格
- 改了结局 vs 旧结局遗留的物理 / 声音 / 镜头 / 禁止项

低优先级的风格愿望与显式的机位 / 身份 / 时长 / 编辑锁冲突时，保锁。

## 10. 默认值

- 用户没给时长：15s，输出时在代码块外注明「时长为补充默认」。
- 画幅无法从平台或素材推断：16:9，同样注明。
- 长视频、延长、明确要精确时间轴：必须问到确切时长，因为它改变结构。
- 素材身份或用途含糊、编辑目标定位不到、延长方向缺失、两段视频顺序不明、输入超平台上限且没有明显的削减方案：这几种才停下来问，且一次打包问完。
