# Seedance 2.5 官方提示词写法（摘自官方使用手册 2026-08）

> 来源：《【即梦】Seedance 2.5 使用手册》（bytedance.larkoffice.com/wiki/RXh5ww6EqighMdkVTMccm2d4n7e）「3.提示词建议」章。
> 与 `seedance.md` 的关系：常规叙事按 12 段详写骨架写；下面这些是**场景专用配方**——真人脸、30s+、延长、编辑、白模时按需取用。官方公式再结构化，句子仍要"事件不是情绪词"，两套不冲突。

## 1. 基础提示词公式

完整提示词 = 【素材描述】+【一句话概述】+【具体情节描述】+【全局补充（结尾）】

- **素材描述**：素材编号（按上传顺序）+ 具体用途（哪个素材是人物 / 音色 / 动作 / 场景）。没传素材可省。
- **一句话概述**：主体 + 地点 + 事件 + 题材/风格 + 特殊运镜。
- **具体情节描述**：分时间轴或故事线写；每个分镜/时间段含 ➕正向描述（画面内容 + 运镜 + 动作 + 台词 + 音效）和 ➖反向描述（"不要字幕""不要 bgm"）。
- **全局补充（结尾）**：再强调贯穿全片的元素（机位 + 环境特征 + 整体声音/氛围 + 光影），以及全局禁止项（字幕、bgm 可在此再强调一次）。
- prompt 全文可**多次 @图/视频/音频**，越多次越准。

## 2. 真人人物公式（动画人物同样适用；治"AI 脸/双胞胎脸"）

人物 = [年龄/种族] + [肤色/皮肤质感] + [面部细节特征] + [眼神/灵魂] + [发型/发色] + [服装/服装质感] + [体型/情绪/气质] + [其他要求]

各维度细分公式：

| 维度 | 细分公式 | 例 |
|------|---------|----|
| 年龄/种族（人物基调） | 具体岁数 + 国籍/人种 + 风格形容词 + 脸型名词 | 22 岁东亚女性，清冷古典的骨相脸 |
| 肤色/皮肤质感（避免扁平白） | 冷暖色调 + 肤色名词 + 质感形容词 + **强制保真后缀「保留真实的微细毛孔与肌肤纹理」**（可加雀斑/瑕疵） | 暖调蜜糖色，鼻梁淡淡真实雀斑，保留微细毛孔 |
| 面部细节（辨识度） | 眼型 + 眉骨 + 鼻梁 + 唇形 + 下颌线/骨相，至少组合 3-4 点 | 上挑丹凤眼，立体眉骨，下颌线刀削般利落 |
| 眼神/灵魂（情感） | 眼神形容词 + 目光传达的信息/比喻 + 底层情绪 | 眼神空洞像黑洞，锐利压迫，透着危险 |
| 发型/发色（状态氛围） | 发色 + 状态/质感 + 发型名词 + 环境互动（风吹/凌乱） | 焦糖棕微卷长发，刚睡醒般蓬松凌乱 |
| 服装/质感（风格侧写） | 版型 + 颜色 + 服装名词 + 材质/新旧 + 穿着细节 | 做旧深棕机车皮夹克，真实磨损折痕 |
| 体型/情绪/气质（构图+故事感） | 骨架/肩部 + 构图/镜头要求 + 动作/视线 + 氛围词（若全文已写构图镜头可去掉中间两项） | 骨架宽大，低机位仰拍全身，侧身回瞥，硬核悲壮史诗感 |

## 3. 30 秒长视频公式（配合时间戳）

总述名称（一句话基调，如「29 秒一镜到底（古装女子江边告别）」）+ 三模块：

- **模块一【多模态参考层】**（没传素材可省）：基于上传的[素材类型]，严格保持[……]一致，严格锁定[……]。例：基于上传的[图片]，严格保持@图1 的人物面孔一致性，保持@图2 的构图/空间关系一致，严格锁定人物站位。
- **模块二【全局设定】**（世界观 + 防崩坏）：[基础环境与质感（时间+地点+氛围+强调极致真实物理质感）] + [视觉风格（电影感/写实/二次元 + 景深 + 打光）] + [镜头语言（景别/视角+描述）] + [人物造型（套上面真人公式或 @参考图）] + [表演核心（成片重点）] + [禁止项（声音/字幕/行为/易崩坏处，如：禁止大幅度肢体动作、禁止多余台词或 BGM、禁止字幕）]。
- **模块三【时间戳剧本分镜】**：切成若干时间切片，每片 = [开始秒-结束秒] + [核心阶段/主题] + [动作/表情等物理指令（景别+构图+人物细节动作）] + [情感解析/镜头调度潜台词（向 AI 解释物理指令的深层表达）]。要切镜就把「视频延长」节的转场公式写进对应切片。

## 4. 超长视频（60–180s）

写法同基础提示词，重点是素材 @清楚 + 故事讲清楚，外加开头一段：

完整提示词 = 【全局参数（时长几分钟、画幅比例——因为视频长，开头再强调一遍）】+【素材描述】+【一句话概述】+【具体情节描述（按秒段直写故事线）】+【全局补充】

## 5. 视频延长

- **常规延长**（动作自然延续）：必含词汇「向前延长 / 向后延长 / 延续 / 续写」之一 + 强制约束「要求延长自然、动作衔接流畅自然，禁止生硬切镜、禁止物体凭空出现」。可另传图/视频/音频。例：`参考@视频1 的内容，延长视频 5s 向后延长。要求延长自然……@图1 壮汉战士突然察觉异样，停下脚步摆出防御姿态。`
- **切镜/转场延长**：切镜设定 = [转场类型指引] + [基础约束要求（镜头 A 内容 → 过渡 → 镜头 B 内容）] + [切镜逻辑要求（再强化"必须自然切换场景"，可加景别变化：由特写转中景）]。
- 拿不准就让模型自选：`请从 [自然镜头切换 / 遮罩转场 / 水墨转场 / 相似物转场] 中根据本片风格选择最合适的一种。`

**官方转场词库**（写法统一：「需要在切镜处使用"XX"转场（禁止生硬切镜、禁止物体凭空出现）」+ 描述 A→B）：

| 转场 | 是什么 / 适用 |
|------|--------------|
| 自然镜头切换 | 无过渡效果的干净切换，强调镜头呼吸感、时长协调；绝大多数常规叙事 |
| 淡入淡出 | 画面渐黑（白）再浮现；开头结尾、时间流逝、剧情段落终结 |
| 叠化 | A 变透明同时 B 浮现，1-2s 重叠；回忆、梦境、抒情过渡 |
| 白闪/黑闪 | 瞬间闪白/黑后极速切换；卡点、混剪、紧张氛围（配重音） |
| 擦除 | B 像推拉门把 A 推走；复古风、明显地点转移 |
| 遮罩转场 | 镜头被物体（墙/背影/树叶）遮挡变黑后拉开已是新场景；空间跨越 |
| 相似物转场 | A 尾帧与 B 首帧形状/轮廓/颜色相似（圆月→咖啡拉花）；蒙太奇 |
| 动作转场 | 镜头猛甩产生运动模糊，B 顺同方向甩入；动作片、跑酷、Vlog |
| 动态接力转场 | 人物动作跨镜衔接（A 跳出画框，B 从上方落入）；换装、跨地拼接 |
| 拉近/拉远转场 | 无限放大细节（瞳孔/锁孔）至其内部展开为 B 全貌；套娃式宏微切换 |
| 水墨转场 | 画面如浓墨入水晕染消失，B 从墨迹中浮现；古风、东方美学 |

## 6. 智能编辑 / 高级编辑 / 视频编辑

三者关系：智能编辑=文字改视频；高级编辑=智能编辑＋框选/画笔（针对生成后视频）；视频编辑=同高级编辑但针对本地上传视频。

- **文字编辑公式**：[具体修改对象] + [动作与变化描述] + [生效时序]。必含词汇：「编辑视频里的 xx / 增加 / 加上 / 删除 / 去掉 / 修改 / 替换 / 改成」。写清 A→B。例：`在视频的 1-8 秒，把男生的牛仔裤，替换为深黑色的西装裤`；`把整个视频 0-5 秒，白色的背景都变成绿幕背景。去掉声音，保持静音。`
- **圈选/标记版公式**（高级/视频编辑）：**[标注工具与方位]** + 上式三段。标注工具：不同颜色的框/线/箭头/文字/地标点（+橡皮擦）。要点：写明用什么工具画的、AI 该看工具里面还是外面（"红框内""沿红色箭头指向的区域""红线左侧"）。
- **生效时序**要点：写明修改是全片一致还是特定秒段（"全片统一修改保持一致""仅在第 5-8 秒期间发生变化""从第 3 秒起逐渐显现"）。

## 7. 白模

两档，**当前粗颗粒度效果更好**：

- **粗颗粒度**（几何体拼的低保真 3D 白模，当动态骨架用：提供运动轨迹/运镜/站位/光影/切接参考，从零生成新视频）：
  【参考声明】参考[视频1]的{运镜|动作|动线|光影变化|角色站位|音乐音效|画面节奏}
  +【对应关系映射】将[视频1]中的{颜色/形状特征}模型替换为[图X]的{角色名}……（逐个映射）
  +【剧情详述】按时间线写动作/表情/台词/光影
  +【场景处理】文字描述或 @场景图
  +【收束】整体风格 + 画质 + 一致性约束 + 音频处理
  ⚠️ 模型带四肢/翅膀时要写出四肢完整动作序列，否则动作僵化；最佳实践是不上传带四肢翅膀的白模。
- **细颗粒度**（建模完整、结构清晰的 3D 模型，直接渲染上材质/光影/风格）：
  【渲染指令】将[视频1]的白模动画渲染成最终成片
  +【分段渲染描述】0-Ns：{背景环境、色调氛围、人物材质、光影效果}；Ns {转场触发点与方式}：{新场景渲染描述}
  +【场景处理】+【整体收束】（新场景环境、人物渲染保持不变/随场景变化、音频处理）
  ⚠️ 上传参考视频需去除轨迹线/坐标线/相机 cone 等干扰信息。
- 白模仅作参考、不想照搬时，明说：`@视频1 是白模 viewport reference，只用于参考角色大小关系、站位方向、镜头距离和空间压迫感。不要照抄白模动作，最终画面不能保留白模质感。`
