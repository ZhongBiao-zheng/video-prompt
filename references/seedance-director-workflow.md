# Seedance 导演流程：工作流 / 素材锁定表 / 输出模式 / 时间轴模式

> 吸收自 liyue-aigc/seedance-2-5-video-director（2026-09-04），按本 skill 简派改造：默认仍只输出 prompt 本体，下列重流程按请求复杂度启用。

## 0. 标签规范

素材统一写 `@Image N` / `@Video N` / `@Audio N`，N 按用户上传顺序编号，不改序、不合并。用户用「图片1 / 图1 / 第一张」时，映射成 `@Image 1` 并在代码块外注明映射。一张图一个身份；一个素材承担多种用途时拆成多条引用。

## 1. 流程分档

| 档位 | 触发 | 走哪几步 |
|------|------|---------|
| 轻 | ≤15s、素材 ≤2、无延长 / 编辑 / 白模 / 转场 | 步 1 → 2 → 8 → 9 |
| 中 | 16–30s，或素材 3–5，或有台词 / 真人表演 | 步 1 → 2 → 3 → 7 → 8 → 9 |
| 重 | 30s+ / 长视频 / 延长 / 编辑 / 白模 / 无缝转场 / 多宫格 / 用户要「导演方案」/ 用户给了范例要「按这个结构」 | 全 9 步 |

## 2. 九步工作流

1. **锁请求**：模式（基础 / 精确时间轴 / 长视频 / 延长 / 编辑 / 白模 / 无缝转场 / 多宫格）、交付物（只要 prompt / 导演方案 / 只要脚本 / 只诊断 / 按原结构改写）、时长、画幅、语言、声音策略。用户没给的标「补充默认」（15s / 16:9）。
2. **盘素材**：只用用户真给的或明确编号的素材，规范为 `@Image N / @Video N / @Audio N`。
3. **建素材锁定表**（见 §3）。无素材可省。
4. **锁范例继承**：用户给了范例 prompt 时，列出继承哪些维度：层级 / 颗粒度 / 时间 / 故事 / 机位 / 表演 / 风格 / 素材范围。「参考这个结构」只继承层级与颗粒度。
5. **点专项能力**：只加请求需要的——真人脸公式、多人锁、音色绑定、去 BGM、创意迁移、局部消除替换、视角重建、绿幕合成。每条绑到具体主体 / 来源 / 目标 / 时间段。
6. **选公式与控制深度**：按模式取 `seedance-2.5-official.md` 里的配方；用户给的范例有多细就写多细，不把高控制范例压成短 prompt，也不把简单请求写成时间戳剧本。
7. **写连续性锁**：只写相关的——身份、人数、服装、道具归属、地理、主体尺度、镜头轴线、光向、色板、材质、声音、台词、受保护的原片。
8. **起草**：prompt 内部顺序 = 开头一行全局意图（风格 + 事件）→ 主体 / 场景 / 音乐 → 按时序的事件（Shot 或时间轴）→ 结尾约束行（连续性 + 禁止项）。所有档位都带头尾两行；轻档各一行，中重档约束可两三行。
9. **审**：时长、台词是否塞得下、引用是否都存在、模式语法、素材角色、因果、机位、连续性、编辑范围、声音策略、范例继承范围、矛盾（清单见 `seedance-direction-patterns.md` §9）。

## 3. 素材锁定表

```
| 素材 | 用途 | 生效时段 | 保留 | 不继承 |
|------|------|---------|------|--------|
| @Image 1 | 主角身份（完整可见人物） | 全片 | 脸 / 发型 / 服装 / 体型 / 配饰 | 背景 / 姿势 / 构图 / 文字 |
| @Video 1 | 动作参考 | Shot 03 | 起跳—挥砍的重心与节奏 | 人物 / 场景材质 / 声音 |
| @Audio 1 | 音色 | Shot 05 台词 | 低沉音色 / 语速 / 停顿 | 背景噪声 / 其他说话人 |
```

用途取值：身份 / 场景 / 道具 / 风格 / 分镜图（图）；原片 / 动作 / 机位 / 编辑目标 / 转场 / 白模（视频）；音色 / 台词 / BGM / 节奏 / 环境声（音频）。表只列用户真给的行。

## 4. 输出模式

| 模式 | 触发词 | 输出 |
|------|-------|------|
| `prompt-only`（默认） | 无说明 / 「只要提示词」 | 一个代码块，prompt 本体；操作信息（时长 / 抽卡 / 映射 / 补充默认）放代码块外一两行 |
| `full-direction` | 「导演方案」「完整方案」「帮我策划」，或重档请求 | 四段：**导演方案**（模式 / 时长画幅 / 一句话意图 / Shot 或时间轴概览）→ **素材映射**（§3 表）→ **连续性与禁止项** → **最终提示词**（唯一一个代码块） |
| `script-only` | 「只要脚本」 | 可演的剧本：前提、人物心理（需要时）、Shot 或时间轴、台词原文、可见表演、机位、声音、结尾状态；不带素材表和 prompt |
| `diagnosis-only` | 「只诊断」「看看哪里冲突」 | 指出原因和具体矛盾（引用原句），不重写整段 |
| `revision` | 「按原结构改写」 | 保留原结构与未变部分，先两三行列出实质改动，再给改后版本 |

full-direction 的前三段用 markdown 列表 / 表格；最终提示词块内仍遵守简派输出铁律（纯文本、无标题、无加粗）。

## 5. 时间轴模式（替代 Shot 编号）

默认用 `Shot 01 / Shot 02`；≥30s 默认 `Shot 01【阶段功能】`（方括号 2–4 字写该镜叙事任务）。以下情况切时间轴：用户明确要「精确时间轴 / 卡点 / 第 N 秒」、精确 30s、长视频（30–180s）、延长与编辑要写生效秒段、白模细颗粒度分段渲染。

格式：

```
0-3s【阶段功能】：可见动作 / 表情 + 机位景别 + 声音或台词 + 结束状态。
3-8s【阶段功能】：……
```

规则：

- 切片连续、不重叠、加起来等于总时长；边界写法全片一致（`0-3s, 3-8s`）。
- 每片留够动作时间；塞不下先减事件，不把动作压进不合理的短片。
- 台词按 3–5 字/秒核对；听、停顿、反应算进该片。
- 长视频用「幕 / 场」而非逐秒微操：每场给叙事任务、大致或精确时段、地点、动作、机位策略、转场；场与场之间维护状态链（位置 / 服装 / 手持道具 / 时间天气 / 未完成目标）。
- 一镜到底时，时间戳标题是表演节拍，不是切镜；景别只能靠机位或主体移动改变。
- 情绪解读只在能转成可见表演、视线、呼吸、姿态、语气、机位时才写。

## 6. 提问纪律

只在这些情况停下来问，且一次打包：素材身份或用途含糊；编辑目标定位不到；延长方向缺失（「新增片段放原片之前还是之后？」）；两段视频顺序不明；两个主模式都说得通且会产出不同 prompt；输入超平台上限且没有明显削减方案。其他一律用补充默认推进。
